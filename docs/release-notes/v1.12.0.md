Armour stands as they are posed, and updates to new Minecraft versions that start by themselves.

## New

- **Armour stand poses**: head, body, arms and legs turned the way they were set with commands or in the
  world, the armour following them; arms and the base plate only when shown, small stands, items held even
  without arms and a chestplate's sleeves on armless stands. Stands wiggle when they are hit.
- **A weekly watch for new Minecraft releases** (the `watch-minecraft` workflow): when Mojang releases a
  version Fabric supports, the update is tried on its own branch with the build and the server test, the game
  classes the viewer ports are compared, and an issue lists the result, the changed classes grouped by the
  viewer files they belong to, and what is left to do. See docs/UPDATING.md.

## Updating

Replace the jar in `mods/` and restart the server. Configuration and cameras stay as they are.
