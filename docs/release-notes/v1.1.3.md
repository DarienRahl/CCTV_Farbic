Cameras stream again after a quiet minute, sign text is drawn like in the game, and the mod is
ready for easy updates to new Minecraft versions. Part of the [roadmap](../ROADMAP.md) (1.1.x
stability, 1.2 easy updates, 1.3 1:1 picture).

## Fixed

- **Cameras stayed empty when nobody had watched them for a minute.** A dedicated server with no
  players online pauses itself after `pause-when-empty-seconds` (60 by default) and then skips
  its ticks, and the camera streams stopped with them: the page connected but stayed empty until a
  player joined. A watched camera now counts as a player online for that setting. While someone
  watches, the server keeps running and the viewer shows the live world. Once the last viewer
  leaves, the server pauses as usual.

## New

- **Signs and hanging signs show their text**, front and back, in the game's font, with the
  game's sign layout: dyed text, glowing text (with the outline for black glowing text or when
  the camera is close), lit like the game, visible up to 64 blocks. Edits (sign editing,
  `/data merge`, dye, glow ink) appear right away.
- **Soft failures.** When something that talks to the game fails (a camera, one entity, sky and
  weather sampling, reading a section, a block state, block update tracking), the problem is
  logged once and that part is skipped. The game server is never taken down. A failing camera
  disconnects its viewers, and they reconnect to a fresh one.
- **`/api/status`** shows the state of every live camera session: whether it ticks, its viewers,
  their download progress and backlog. Useful when a camera does not load.

## For developers: easy updates

- `docs/ROADMAP.md`: the plan (1:1 picture, performance, easy updates), with milestones.
- `docs/UPDATING.md`: the update procedure and the list of every place the mod touches the game.
- **`update-minecraft` workflow:** give it a game version and it finds the matching Fabric Loader
  and Fabric API, bumps the build files, pushes `update/<version>` and runs the build and the
  real-server test on it.
- **`inspect-minecraft` with `compare_with`:** decompiles the game classes the viewer ports to
  JavaScript (`docs/ported-classes.txt`) in the old and new version and prints the differences.
- The CI server test now also covers sign text and a viewer arriving after the server paused.

## Updating

Replace the jar in `mods/` and restart the server. Configuration and cameras stay as they are.
