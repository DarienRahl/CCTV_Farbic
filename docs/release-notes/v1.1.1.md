Everything is now in English: in-game command messages, the web viewer and camera list, the README
and the release notes. No gameplay or rendering changes compared to 1.1.0.

## Changed

- `/cctv` command feedback, help and errors are in English.
- The web viewer (status, loading messages, settings panel, toolbar, HUD) and the camera list page
  are in English.
- README and release notes translated to English.

## Updating

Replace the jar in `mods/` and restart the server. Configuration, cameras, shaders and sky boxes
stay as they are.

See the [1.1.0 release](https://github.com/DarienRahl/CCTV_Farbic/releases/tag/v1.1.0) for the big
list of features (all mob models, huge view distance, weather, End flashes, shaders, sky boxes).
