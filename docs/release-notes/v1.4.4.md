The viewer's pages now speak the game's font, and the README shows the latest release.

## New

- **The game's font on every page**: the camera list, the buttons, the settings, the HUD, the messages and the
  labels burnt into recordings are written in Minecraft's own font. The server builds it as a web font from the
  game's glyph sheets (`/assets/font/minecraft.ttf`), with a bold face made like the game's bold, so a resource
  pack that changes the font changes the pages too. Characters the game's sheets do not have fall back to the
  browser's font.
- **HUD like the debug screen**: the camera's name, place, clock and status sit on translucent grey boxes like
  the lines of the game's F3 screen, readable over bright skies and snow.

## For developers

- The README's "How it works" is a Minecraft-style picture drawn by `.github/scripts/roadmap.py` (no game
  textures), checked by CI like the roadmap.
- The `screenshots` workflow takes the README's pictures from a real server with the released version and
  commits them; the release workflow runs it after publishing a release.

## Updating

Replace the jar in `mods/` and restart the server. Configuration and cameras stay as they are.
