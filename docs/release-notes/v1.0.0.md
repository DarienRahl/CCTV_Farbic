First release. A **server-side only** mod for **Fabric / Minecraft 26.3**: place a camera in the
world with a command and watch its live picture in a web browser.

## Features

- **Players do not need the mod.** They join with a normal vanilla client.
- **No extra account and no bot.** The server itself reads blocks, light, biomes and entities from
  loaded chunks.
- **No GPU on the server.** The browser renders the picture (WebGL2). Data goes over HTTP
  (Server-Sent Events) on port `8100`.
- **Live.** Players and mobs are sent 20 times a second with smooth interpolation, and block
  changes (doors, placing, breaking) show up right away.
- **Looks like the game:**
  - original block textures and models, *smooth lighting* with ambient occlusion, a day and night
    lightmap, torches;
  - biome colours, animated water and lava, the sun, moon phases, stars and clouds;
  - mobs with their game models and textures, player skins and armour;
  - chests, items on the ground and in hands, shadows under mobs.
- **Commands:** `/cctv create <name>` places a camera where you are looking. There are also `move`,
  `aim`, `fov`, `range`, `remove`, `list`, `url` and `info`.
- **Web page:** camera list, video wall and colour, black-and-white and night vision modes.

## Installation

1. Download `cctv-fabric-1.0.0.jar` below and put it into the server's `mods/` folder together with
   **Fabric API**. **Java 25** is required.
2. Start the server and open port **8100/TCP**.
3. In game type `/cctv create gate`, then open `http://SERVER-IP:8100/`.

On the first start the mod downloads the official 26.3 `client.jar` from Mojang's servers (about
30 MB, once) and takes the textures for the browser from it. Nothing is sent to players. You can
turn this off in `config/cctv/config.json` (`downloadClientAssets`); the viewer then uses colours.

## Limitations

- A camera only sees loaded chunks. Use `/forceload` for places without players.
- Signs, beds and banners are simplified shapes. Rarer mobs have simplified models. Rain and
  particles are not drawn.

The full description, configuration and API are in the README of the repository.
